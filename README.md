# 🌐 Personal Portfolio Website

## 📌 Overview
This is a personal portfolio website developed using HTML, CSS, and JavaScript. It showcases my skills, projects, and personal information in a clean and responsive layout. The project also includes a basic backend setup using Python and SQLite for managing project data.

---

## 🚀 Features
- Responsive portfolio design
- Sections: About, Skills, Projects, Contact
- Clean and user-friendly UI
- Backend support for project data management
- SQLite database integration

---

## 🛠️ Tech Stack
**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Python
- SQLite

---

## ⚙️ Backend Details
The backend is implemented using Python scripts with SQLite database.

- `init_db.py` → Initializes the database and creates required tables  
- `insert_projects.py` → Inserts project data into the database  
- `database.db` → Stores project information  

---
## 🧪How to Run Locally
Clone the repository:
git clone https://github.com/Shagunkashyap1202/portfolio-website.git
Navigate to the project folder:
cd portfolio-website
Run backend scripts:
python init_db.py
python insert_projects.py
Open index.html in your browser
